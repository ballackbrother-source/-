# CHANGELOG — ETERNIA ～星を継ぐ者～

## v1.0-demo（完成版デモ） — 2026-06-09

ブランチ `claude/fantasy-rpg-design-ISs8y` を**完成版デモ**として確定。
外部画像なし・バニラ JS + Canvas 2D・ビルド不要のまま、MVP（本編プロローグ〜第2章
＋終盤体験版＋裏ボス）にアート/演出/UXの全面強化を適用。

**品質**
- フルQA `npm run qa`（flow.mjs）: 10/10 PASS（本編全フロー）
- スモーク `npm run smoke`（play.mjs）: コンソールエラー 0 件

**主な強化（イラスト調リニューアル）**
- アート：タイル/人物/モンスターを陰影・グラデ・リムライト・キャストシャドウ付きへ。
  系統別に判別できるモンスター（竜=横向き全身の咆哮ポーズ、魔導 ほか）、主人公は冒険者装備
- アニメ：全モンスターの待機/パーツ動作、被弾/攻撃モーション、まばたき、NPCの小芝居
- 戦闘演出：ボス登場（ズーム＋WARNING）、全体/単体魔法の属性エフェクト、弾むダメージ数字
  （会心=特大＋光輪）、行動順インジケータ、状態異常マーカー、勝利リザルト、戦闘背景のマップ連動
- フィールド：場所別ライティング＋ビネット、天候（雨/雪）、宝箱開封演出、足元エフェクト、
  点光源、隊列移動、ミニマップ
- UI：イラスト調ウィンドウ/ゲージ、ミニアイコン（道具/装備/属性）、会話フェイス（まばたき）＋
  自動折り返し＋タイプ音、どうぐ屋の買う/売る、図鑑の作り込み、セーブ/ロードのカード表示、
  タイトルロゴ（光沢＋流れ星＋雲）

**起動**
```
node tools/serve.js 8080   # → http://localhost:8080/rpg/
```
（ES Modules のため `file://` 直開きは不可。静的サーバ経由で開く）
