# 6. マップ設計

## 6-0. 構造方針

- **ワールドマップ（俯瞰移動）＋ 町（拠点）＋ ダンジョン（攻略）** の古典三層構造。
- 移動手段の段階解放で世界が広がる王道進行：**徒歩 → 船（第3章）→ 飛行手段（終章・天空回廊の浮遊艇）**。
- 各ダンジョンに必ず：**①分岐宝箱 ②隠し通路/隠し部屋 ③小さな物語（ミニイベント or 手記）④ギミック1種**。
- ファストトラベル：訪問済みの町へワールドマップから瞬時移動可（探索ストレス軽減）。

## 6-1. ワールドマップ

```
              [雪原コルド]        [天文都市ステラ]──[天空回廊→エテルナ・コア]
                 │ 北西              │ 北東
   [ルミナ]──[ハーフェン]──[聖都アルゲンタ]──[終末の街ノクス]
     (北端)        │ 中央街道           │
                   │                  │ 東
              [イグ＝カザン]──[港町マレア]══船══[聖樹の里ユグル]
                 (南・火山)      (南東港)        (東・樹海/島)
```
- **エリア区分と環境**：北＝寒冷（雪・枯れ地）／中央＝草原・街道／南＝砂漠・火山／東＝樹海・海。
- **星の翳り表現**：第七星に近いエリアほど大地の色が褪せ、進行と共に（炉停止・浄化で）色が戻る**動的ワールド**。エンディングで全土が彩りを取り戻す。
- **ランダムエンカウントなし**：フィールドにモンスターシンボルを配置。レベル帯で出現種が変わる。

### ダンジョン設計テンプレ（実装用）
- 全長：小=15分／中=30分／大(炉・回廊)=45分。途中に**セーブ像**を1–2個。
- 宝箱配置：道なり宝箱（消耗品）＋**寄り道宝箱（装備）**＋**隠し宝箱（レア/素材）**。
- 各ダンジョンに**「手記/石碑」1つ**で世界観を断片配信（最終的に物語の伏線に接続）。

## 6-4. 隠し要素

| 種類 | 例 | 入手 |
| --- | --- | --- |
| 隠し通路 | 怪しい壁・偽の行き止まり | 全ダンジョンに最低1 |
| 隠しボス（中） | 各エリアの「徘徊する強敵シンボル」 | レア装備・素材 |
| 隠しイベント | §09。仲間の過去の決着・幻の村 | 絆/最強装備 |
| ミニゲーム | 闘技場・釣り・星図観測・カジノ(コイン交換) | 限定装飾品・コイン景品 |
| 図鑑コンプ報酬 | モンスター/アイテム図鑑100% | 称号・裏ダン鍵の一部 |
| 隠し移動先 | 船で行ける孤島・回廊で行ける浮遊遺跡 | 最強装備の素材／裏ボス入口 |

> **探索のご褒美密度ルール**：プレイヤーが「寄り道して損した」と感じる瞬間を作らない。脇道の先には必ず**装備・物語・ショートカット**のいずれかを置く。
