# 9. エンドコンテンツ

## 9-0. 方針

- クリア後＝**「育成・収集・物語」の総決算**。本編で蒔いた全要素を回収する場。
- 解放はクリア後セーブ（「つよくてニューゲーム」ではなく**クリアデータ続行**）。本編の世界がそのまま延長され、各地に変化が起きる。
- 目標は3つ：**①裏ダンジョン踏破 ②最強装備の完成 ③真エンディング到達**。

---

## 9-1. 裏ダンジョン「星墜の深淵」

| 項目 | 内容 |
| --- | --- |
| 入口 | クリア後、故郷ルミナの星見の丘に**星の裂け目**が出現（ペンダントが反応） |
| 構造 | **全7層 + 最深部**。各層が本編7属性に対応したテーマ（炎/氷/雷/風/土/光/闇の試練） |
| 推奨Lv | 55→70（層ごとに上昇） |
| 仕掛け | 各層に**「過去の章ボスの強化版（リベンジ）」**を配置。属性試練＋星詠必須の謎解き |
| 特徴 | セーブ像は層の境のみ＝緊張感。中断は星帰りの石で。道中に最強素材が眠る |
| 各層ボス | 強化版：ヴェルダンテ改/オルランド改/ネレイド改/ガーディアン改/フリーズ改/ノクスエンド改/堕聖王改（全て新ギミック追加） |

- 層ごとに**「仲間の過去の決着」隠しイベント**（§9-3）と**ステ上昇種**を1つずつ配置。
- 全層の**石碑7枚**を読むと、創世神話§1-5の"省略された一節"が明かされ、裏エンドの台詞が変化。
