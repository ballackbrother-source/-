# 5. バトルシステム

## 5-0. 基本仕様

- **ターン制コマンドバトル**（ドラクエ／初期FF系）。サイドビュー（敵右・味方左）。
- 戦闘参加：**前衛最大4人**。コマンド：**たたかう／スキル／魔法／アイテム／ぼうぎょ／にげる**。
- **行動順**＝ターン開始時に各キャラ/敵のAGIで決定（`行動値 = AGI * rand(0.9–1.1)`、降順）。**ヘイスト/スロウ**で増減。
- **先制・不意打ち**：フィールドでのシンボルエンカウント（敵が見える）。背後・奇襲スキルで先制率上昇、被発見で不意打ち（敵先攻＋初手回避不可）。
- エンカウント方式は**シンボルエンカウント**（全年齢のストレス軽減・理不尽回避）。

## 5-1. ダメージ計算式（正本）

### 物理ダメージ
```
基礎 = 物理攻撃 * 2 - 物理防御
補正 = 基礎 * 属性倍率 * 会心倍率 * 乱数(0.90–1.10) * 隊形補正
ダメージ = max(1, floor(補正))
```
- **会心（クリティカル）**：会心倍率 = 2.0（発生率は §04-2）。会心は防御の一部を貫通（防御×0.5で再計算）。
- **隊形補正**：前列1.0／後列の物理は与・被ともに0.7（後衛保護）。

### 魔法ダメージ
```
基礎 = (魔法攻撃 * 威力倍率) - 魔法防御
補正 = 基礎 * 属性倍率 * 乱数(0.90–1.10)
ダメージ = max(1, floor(補正))
```
- **威力倍率**：魔法ごとに設定（初級≒2.5／上級≒6.0、全体は単体の0.7掛け）。

### 回復
```
回復量 = (SPI * 回復倍率) * 乱数(0.95–1.05)
```

### 命中・回避
```
命中判定: rand(0–99) < 命中率 - 回避率 なら命中
```

## 5-2. 属性相性（7属性）

倍率：**弱点 ×1.5 ／ 半減 ×0.5 ／ 無効 ×0 ／ 吸収 ×-1.0（回復）／ 等倍 ×1.0**

### 相性チャート（攻撃属性 → 弱点になりやすい敵タイプの指針）
| 攻撃属性 | 弱点を突きやすい相手 | 半減/無効されやすい相手 |
| --- | --- | --- |
| **炎** | 氷/植物/虫 | 炎竜・炎系（吸収あり） |
| **氷** | 炎獣・水棲 | 氷系（吸収あり） |
| **雷** | 機械・水棲・飛行 | 土系・地竜 |
| **風** | 飛行を撃墜・虫 | 岩/土系（半減） |
| **土** | 機械・重装 | 飛行（無効される） |
| **光** | 闇・不死・魔王軍 | 光の精霊（吸収） |
| **闇** | 光の精霊・聖騎士 | 不死・魔王軍（吸収/無効） |

> **対の関係**：炎⇔氷、雷⇔土、光⇔闇 は互いに「片方が吸収すると片方が弱点」という鏡像で設計し、覚えやすく。風は「飛行特効＋汎用」のニュートラル枠。
> **属性は二重持ち可**（例：炎竜＝炎吸収・氷弱点・物理半減）。ボスは複数属性耐性を持ち、`ルゥの星詠`で看破させる。

## 5-3. 状態異常・能力変化

### バッドステータス
| 状態 | 効果 | 解除 |
| --- | --- | --- |
| 毒（POISON） | 毎ターン最大HPの1/16減 | 時間/解毒/教会 |
| 猛毒（V.POISON） | 毎ターン最大HPの1/8減 | 解毒上位/教会 |
| 麻痺（PARALYZE） | 一定確率で行動不能 | 時間/解除魔法 |
| 睡眠（SLEEP） | 行動不能・被物理で起床 | 被ダメ/解除 |
| 沈黙（SILENCE） | 魔法/一部スキル封印 | 時間/解除 |
| 混乱（CONFUSE） | 対象がランダム化（味方殴る） | 被ダメ/解除 |
| 暗闇（BLIND） | 物理命中大幅低下 | 時間/解除 |
| 石化（PETRIFY） | 戦闘不能扱い・全員石化で全滅 | 専用/教会 |
| 呪い（CURSE） | 回復量半減・蘇生不可 | 解呪 |
| 即死（DEATH） | 一定確率で戦闘不能 | 耐性/復活 |

- **成功率**＝ `基礎成功率 + (使用者LUK - 対象LUK)*0.5 - 対象耐性`。ボスは多くの状態に高耐性（ただし完全無効にはせず、戦術の余地を残す）。

### 能力変化（バフ/デバフ）
- **段階制**：攻/防/魔攻/魔防/速/命中・回避 を ±3段階（1段＝±25%）。`プロテス/ヘイスト/ブレイブ` 等。重ねがけで段階加算。
- デバフ（`スロウ/ブレイク/フェイント`）でボスの数値を削る戦術が有効。**「正面火力が足りないなら搦め手で勝てる」**設計。

## 5-4. リソース & 連携システム

### TP（テンションポイント）/ 連携必殺
- 戦闘中、与ダメ・被ダメで **TP** が貯まる。最大で**必殺技**を発動。
- **連携必殺（絆システム連動）**：絆ゲージが高い2人が同ターンに条件を満たすと**合体技**が発動（例：ガロード＋ルゥ「双星斬」）。演出＋大ダメージで、戦闘にドラマを持たせる。

### ぼうぎょ・ためる
- `ぼうぎょ`：被ダメ半減＋TP小回復。`ためる`：1ターン溜めて次の攻撃を強化（ボスのチャージと駆け引き）。

## 5-5. ボスギミック設計指針

**全ボスに「観察 → 対応」のループを必ず1つ以上仕込む**。理不尽な即死ではなく、「予兆を見て対処すれば防げる」を徹底（全年齢・"考えれば勝てる"方針）。

### 汎用ギミック・パターン
1. **チャージ攻撃**：ボスが「力をためている！」と予兆 → 次ターン全体大技。`ぼうぎょ`・防御バフ・行動阻害（沈黙/麻痺/ためる解除）で対応。
2. **形態変化（フェーズ）**：HP閾値（例 66%/33%）で行動パターン・弱点属性が変化。`ルゥの星詠`で新しい弱点を看破させる。
3. **部位/付随ターゲット**：本体＋核/腕/砲台。順番を間違えると火力が激化（例：先に砲台を潰す）。
4. **属性ローテーション**：纏う属性を周期で変える → 半減/吸収のタイミングを読む。
5. **状態異常の波**：全体睡眠/混乱など → 解除役の温存と即時対応が鍵。
6. **ギミック解除**：特定スキル/アイテムで「弱点を露出させる」一手（例：氷で炎の鎧を割る）。

### ボス別ギミック概要（詳細ステは §07）
| ボス | 主ギミック |
| --- | --- |
| ヴェルダンテ（章1） | 根を全部倒さないと本体無敵。チュートリアル的部位破壊 |
| 聖騎士団長オルランド（章2） | カウンター構え。物理を誘って魔法で崩す読み合い |
| 水将ネレイド（章3） | 水属性吸収＋全体津波チャージ。雷弱点を星詠で看破 |
| ガーディアン・コア（章4） | 4砲台＋コア。砲台を順に破壊しオーバーヒート（弱点露出）を作る |
| 闇将ノクスエンド（章5） | 全体闇＆即死付与。光バリア（星の加護）前提の耐久戦 |
| 魔王ヴァルゼリオン（終章・3形態） | §5-6 |
| 裏ボス | §09 |

## 5-6. ラスボス戦：魔王ヴァルゼリオン（3形態）の特別設計

**この戦闘は"倒す"だけでなく"わかり合う"を体験させる、本作の集大成。**

- **第1形態：剣聖アルドの姿**。純粋な剣技戦。彼の攻撃は美しく強いが、どこか「わざと隙を見せる」演出（=死を望んでいる伏線）。
- **第2形態：星に蝕まれた魔王形態**。属性ローテ＋全体大技。HPを削るごとに、**ルゥの「星詠」で1000年前の記憶（アルドの孤独）が断片再生**される（戦闘UIにテキストが挿入される演出）。
- **第3形態：暴走する第七星そのもの**。ここで戦闘の勝利条件が変化：**HPを0にする**のではなく、`星詠`＋仲間の連携必殺で**「アルドに想いを届けるゲージ」を満タンにする**。ダメージを与えつつ"赦しゲージ"を溜める二重目標。
- **決着演出**：赦しゲージMAXでルゥが剣を収め、アルドを抱きしめる特殊カットへ（§02-7）。
- **真エンド分岐**：絆イベント全完遂時のみ、最後に**「赦す」コマンド**が出現。選ぶと真エンディングルートへ。未達成なら通常エンド（彼を倒して還す）。

> **設計の肝**：システム（赦しゲージ）と物語（赦し）を完全同期させ、**プレイヤーの操作そのものが感動の主体**になるようにする。
