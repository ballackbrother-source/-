# 5. バトルシステム

## 5-0. 基本仕様

- **ターン制コマンドバトル**（ドラクエ／初期FF系）。サイドビュー（敵右・味方左）。
- 戦闘参加：**前衛最大4人**。コマンド：**たたかう／スキル／魔法／アイテム／ぼうぎょ／にげる**。
- **行動順**＝ターン開始時に各キャラ/敵のAGIで決定（`行動値 = AGI * rand(0.9–1.1)`、降順）。**ヘイスト/スロウ**で増減。
- **先制・不意打ち**：フィールドでのシンボルエンカウント（敵が見える）。背後・奇襲スキルで先制率上昇、被発見で不意打ち（敵先攻＋初手回避不可）。
- エンカウント方式は**シンボルエンカウント**（全年齢のストレス軽減・理不尽回避）。

## 5-1. ダメージ計算式（正本）

### 物理ダメージ
```
基礎 = 物理攻撃 * 2 - 物理防御
補正 = 基礎 * 属性倍率 * 会心倍率 * 乱数(0.90–1.10) * 隊形補正
ダメージ = max(1, floor(補正))
```
- **会心（クリティカル）**：会心倍率 = 2.0（発生率は §04-2）。会心は防御の一部を貫通（防御×0.5で再計算）。
- **隊形補正**：前列1.0／後列の物理は与・被ともに0.7（後衛保護）。

### 魔法ダメージ
```
基礎 = (魔法攻撃 * 威力倍率) - 魔法防御
補正 = 基礎 * 属性倍率 * 乱数(0.90–1.10)
ダメージ = max(1, floor(補正))
```
- **威力倍率**：魔法ごとに設定（初級≒2.5／上級≒6.0、全体は単体の0.7掛け）。

### 回復
```
回復量 = (SPI * 回復倍率) * 乱数(0.95–1.05)
```

### 命中・回避
```
命中判定: rand(0–99) < 命中率 - 回避率 なら命中
```

## 5-2. 属性相性（7属性）

倍率：**弱点 ×1.5 ／ 半減 ×0.5 ／ 無効 ×0 ／ 吸収 ×-1.0（回復）／ 等倍 ×1.0**

### 相性チャート（攻撃属性 → 弱点になりやすい敵タイプの指針）
| 攻撃属性 | 弱点を突きやすい相手 | 半減/無効されやすい相手 |
| --- | --- | --- |
| **炎** | 氷/植物/虫 | 炎竜・炎系（吸収あり） |
| **氷** | 炎獣・水棲 | 氷系（吸収あり） |
| **雷** | 機械・水棲・飛行 | 土系・地竜 |
| **風** | 飛行を撃墜・虫 | 岩/土系（半減） |
| **土** | 機械・重装 | 飛行（無効される） |
| **光** | 闇・不死・魔王軍 | 光の精霊（吸収） |
| **闇** | 光の精霊・聖騎士 | 不死・魔王軍（吸収/無効） |

> **対の関係**：炎⇔氷、雷⇔土、光⇔闇 は互いに「片方が吸収すると片方が弱点」という鏡像で設計し、覚えやすく。風は「飛行特効＋汎用」のニュートラル枠。
> **属性は二重持ち可**（例：炎竜＝炎吸収・氷弱点・物理半減）。ボスは複数属性耐性を持ち、`ルゥの星詠`で看破させる。

## 5-3. 状態異常・能力変化

### バッドステータス
| 状態 | 効果 | 解除 |
| --- | --- | --- |
| 毒（POISON） | 毎ターン最大HPの1/16減 | 時間/解毒/教会 |
| 猛毒（V.POISON） | 毎ターン最大HPの1/8減 | 解毒上位/教会 |
| 麻痺（PARALYZE） | 一定確率で行動不能 | 時間/解除魔法 |
| 睡眠（SLEEP） | 行動不能・被物理で起床 | 被ダメ/解除 |
| 沈黙（SILENCE） | 魔法/一部スキル封印 | 時間/解除 |
| 混乱（CONFUSE） | 対象がランダム化（味方殴る） | 被ダメ/解除 |
| 暗闇（BLIND） | 物理命中大幅低下 | 時間/解除 |
| 石化（PETRIFY） | 戦闘不能扱い・全員石化で全滅 | 専用/教会 |
| 呪い（CURSE） | 回復量半減・蘇生不可 | 解呪 |
| 即死（DEATH） | 一定確率で戦闘不能 | 耐性/復活 |

- **成功率**＝ `基礎成功率 + (使用者LUK - 対象LUK)*0.5 - 対象耐性`。ボスは多くの状態に高耐性（ただし完全無効にはせず、戦術の余地を残す）。

### 能力変化（バフ/デバフ）
- **段階制**：攻/防/魔攻/魔防/速/命中・回避 を ±3段階（1段＝±25%）。`プロテス/ヘイスト/ブレイブ` 等。重ねがけで段階加算。
- デバフ（`スロウ/ブレイク/フェイント`）でボスの数値を削る戦術が有効。**「正面火力が足りないなら搦め手で勝てる」**設計。

## 5-4. リソース & 連携システム

### TP（テンションポイント）/ 連携必殺
- 戦闘中、与ダメ・被ダメで **TP** が貯まる。最大で**必殺技**を発動。
- **連携必殺（絆システム連動）**：絆ゲージが高い2人が同ターンに条件を満たすと**合体技**が発動（例：ガロード＋ルゥ「双星斬」）。演出＋大ダメージで、戦闘にドラマを持たせる。

### ぼうぎょ・ためる
- `ぼうぎょ`：被ダメ半減＋TP小回復。`ためる`：1ターン溜めて次の攻撃を強化（ボスのチャージと駆け引き）。

## 5-5. ボスギミック設計指針

**全ボスに「観察 → 対応」のループを必ず1つ以上仕込む**。理不尽な即死ではなく、「予兆を見て対処すれば防げる」を徹底（全年齢・"考えれば勝てる"方針）。

### 汎用ギミック・パターン
1. **チャージ攻撃**：ボスが「力をためている！」と予兆 → 次ターン全体大技。`ぼうぎょ`・防御バフ・行動阻害（沈黙/麻痺/ためる解除）で対応。
2. **形態変化（フェーズ）**：HP閾値（例 66%/33%）で行動パターン・弱点属性が変化。`ルゥの星詠`で新しい弱点を看破させる。
3. **部位/付随ターゲット**：本体＋核/腕/砲台。順番を間違えると火力が激化（例：先に砲台を潰す）。
4. **属性ローテーション**：纏う属性を周期で変える → 半減/吸収のタイミングを読む。
5. **状態異常の波**：全体睡眠/混乱など → 解除役の温存と即時対応が鍵。
6. **ギミック解除**：特定スキル/アイテムで「弱点を露出させる」一手（例：氷で炎の鎧を割る）。

### ボス別ギミック概要（詳細ステは §07／物語は §02）
| ボス | 章 | 主ギミック |
| --- | --- | --- |
| ヴェルダンテ | 1 | 根を全部倒さないと本体無敵。チュートリアル的部位破壊 |
| 魔王軍四天王（順次） | 2 | 属性・状態異常で攻める王道ボス群。星核探索の関門 |
| 四天王（最終戦・4体連戦） | 2末 | **撃破直後にシオンの裏切りイベント**（戦闘→ムービー） |
| **白銀の執行者シオン** | 3/4 | 元味方ゆえ手の内を知る。こちらの連携を読む高機動戦。HP閾値で離脱（撃破不能の演出戦も） |
| 魔王ヴァルゼリオン | 6 | 実は守護者。**戦って和解→共闘**へ転じる特殊戦（敵対→味方化） |
| **創世神アルディア** | 7 | §5-6（無限回復＋赦しゲージ） |
| 裏ボス | 後 | §09 |

## 5-6. ラスボス戦：創世神アルディア（赦しゲージ・特殊システム）

**この戦闘は「強さ」ではなく「赦せたか」で決まる、本作の集大成。物語は `02_story.md` §2-8/2-9。**

### 赦しゲージ（隠しパラメータ）
- 第4章以降、シオンへの態度で増減する**0〜100の隠し値**。`05` のリソースとは別系統で、GameStateに永続保存。
- **加算源**：ch5の選択「まだ信じたい／理由を聞く」、シオンの過去を知るサブイベント完遂、戦闘中にシオンへ"とどめを刺さない"選択、彼を庇う行動など（詳細テーブルは `12-7`）。
- **減算源**：ch5「絶対に許さない」、シオンへの過剰な攻撃選択など。
- 値はメニューには直接表示せず、**ルゥとシオンの関係性を示す象徴演出**（焚き火の距離・台詞の温度）で間接的に提示する。

### 戦闘フロー
1. **導入**：アルディアが世界の初期化を開始。仲間が一人ずつ消えていく演出の中、**シオンが戻る**（「私は許されない。それでも戦わせてくれ」）。
2. **第1段階：神は不死**。アルディアは**毎ターン全回復に近い超回復（不死性）**を持ち、**通常攻撃ではHPが減らせない**。「神には勝てない」という絶望をシステムで体験させる（数ターン耐える防衛フェーズ）。
3. **赦しゲージ判定**：
   - **ゲージが閾値以上**なら、コマンドに **連携必殺「ラスト・レクイエム」**（ルゥ＋シオン）が出現。
   - 発動すると**神の不死性（超回復）を破壊**し、以降**初めてダメージが通る**ようになる（攻略開放）。
   - **ゲージ不足**なら連携は出現せず、不死を崩せないまま敗北＝Bad Endへ。
4. **第2段階：撃破可能**。不死を剥がした後はフェーズ制の総力戦。属性ローテ＋世界初期化カウンター（一定ターンで全滅級＝DPSと赦しの両立）。

### エンディング分岐（§2-9 と同期）
| 分岐 | 条件 | 結末 |
| --- | --- | --- |
| **True End** | 赦しゲージ MAX で撃破 | シオン生存・仲間全員生還・世界再生 |
| **Normal End** | 赦しゲージ 中 で撃破 | 神は倒すが連携の代償で**シオン死亡**・世界は救われる |
| **Bad End** | 赦しゲージ 低（連携不発） | シオン拒絶→不死を崩せず敗北→**世界リセット** |

> **設計の肝**：**「赦し」こそが不死の神に勝つ唯一の力**。倒す条件を武力でなく"ルゥがシオンを赦せたか"に置き、**システムと主題（赦し）を完全同期**させる。プレイヤーの第4〜7章の選択すべてが、この一戦に結実する。

### 実装メモ
- 赦しゲージ：`GameState.variables.forgiveness`（0–100）。選択イベントの `addVar/setVar` で操作（`event/EventCommands.js`）。
- 連携技解放：戦闘開始時に `forgiveness >= 閾値` を判定し、シオンの一時参加＋専用コマンドを注入。
- 「無限回復」は BattleSystem に**回復無効化フラグ**（`invincibleHeal`）を追加し、連携技ヒットで false に切り替える実装で表現可能。
