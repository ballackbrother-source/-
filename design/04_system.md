# 4. ゲームシステム（マスターデータ正本）

> 本章の数値は**バランス設計の正本**。バトル式は `05_battle.md`、敵側は `07_monsters.md`、装備は `08_items.md` を参照。
> 全数値は **MVP→βで調整前提のたたき台**。`【調整値】` は実装後に必ずプレイテストで再チューニング。

## 4-1. レベル・経験値

- **レベル上限**：メインクリア想定 **Lv50**／エンドコンテンツ込み **Lv70**。
- **必要経験値曲線**（次のレベルまで）：
  `NeedEXP(n) = floor( 12 * n^2.3 + 8*n )`
  - Lv1→2: 約 20 / Lv9→10: 約 1,400 / Lv29→30: 約 17,000 / Lv49→50: 約 53,000 / Lv69→70: 約 113,000
  - 設計意図：序盤サクサク、中盤に1段壁、終盤はやり込み前提でゆるやかな指数。
- **累計経験値（目安）**：Lv30到達 ≒ 約14万EXP／Lv50 ≒ 約63万EXP。
- **取得経験値**：敵ごとに `baseEXP`（§07の表）。**控えメンバーにも 50% 配分**（育成ストレス軽減・パーティ入れ替え推奨）。
- **レベル差補正**：自分のLvが敵Lvより **+10以上** 高いと取得EXP・Goldが段階的に減衰（最低10%）。低レベル狩り対策＆適正帯誘導。

## 4-2. ステータス（9種）

| 略称 | 名称 | 主な効果 |
| --- | --- | --- |
| **HP** | 体力 | 0で戦闘不能 |
| **MP** | 星霜力 | 魔法・スキルの消費 |
| **STR** | ちから | 物理攻撃力の主係数 |
| **VIT** | みのまもり | 物理防御・最大HP補正 |
| **AGI** | すばやさ | 行動順・回避・先制率 |
| **DEX** | きようさ | 命中・会心率・盗む成功率 |
| **INT** | かしこさ | 攻撃魔法威力 |
| **SPI** | せいしん | 回復魔法威力・魔法防御・最大MP補正 |
| **LUK** | うん | 会心・状態異常成功/耐性・レアドロップ |

### 二次パラメータ（自動算出）
```
最大HP   = baseHP + VIT * 4 + Lv * 3
最大MP   = baseMP + SPI * 3 + Lv * 2
物理攻撃 = STR * 2 + 武器ATK
物理防御 = VIT * 1.5 + 防具DEF
魔法攻撃 = INT * 2 + 武器/装飾MAT
魔法防御 = SPI * 1.5 + 防具MDF
命中率   = 90 + (DEX - 敵AGI) * 0.5 （上限99 / 下限20）
回避率   = (AGI * 0.4 + LUK * 0.1)   （上限60）
会心率   = 3 + (DEX*0.1 + LUK*0.2) ％
```

### レベルアップ成長
- キャラごとに **成長タイプ**（S/A/B/C）を各ステータスに設定。`成長量 = round( typeWeight * (1 + Lv*0.02) )`。
  - 例：ルゥ STR=A, VIT=B, AGI=B, INT=B, SPI=B（バランス）／ガロード STR=S, VIT=S, AGI=C（脳筋）／フィーナ SPI=S, INT=A, VIT=C（後衛）。
- **typeWeight**：S=3.0 / A=2.2 / B=1.6 / C=1.0。
- 成長タイプ表は別紙スプレッドシート `balance_growth.xlsx` で管理（本書は方針のみ）。

## 4-3. ジョブ（クラス）システム

- **基本ジョブ固定 ＋ サブジョブ習得制**のハイブリッド。各キャラは固有の**基本ジョブ**を持ち、進行で**サブジョブ**を1つ装備できる（FF5ほど自由ではなく、王道の"色付け"程度）。
- ジョブはレベルとは別の **JP（ジョブポイント／戦闘で微量取得）** でスキルを習得。
- **キャラ固有基本ジョブ**

| キャラ | 基本ジョブ | 上位ジョブ（章進行で覚醒） |
| --- | --- | --- |
| ルゥ | 星継ぎの剣士 | **星詠の勇者**（終章） |
| ガロード | 剣闘士 | 守護闘士 |
| フィーナ | 星詠みの巫女 | 大神官 |
| シノ | 盗賊 | 暗殺者 |
| リリ | 魔導技師 | 機巧博士 |
| エイル | 帝国剣士 | 七聖剣士 |

- **サブジョブ（共通・誰でも装備可）例**：剣士／魔法士／僧侶／狩人／賢者／踊り子。サブジョブ装備でそのジョブの一部スキルとステ補正が乗る。
- **覚醒（上位ジョブ）**：物語上のキーイベントで解放。専用必殺技と能力上限解放。**＝レベル以外の"強くなった実感"の演出装置**。

## 4-4. スキル & 魔法

### 習得方式
- **魔法**：ジョブ＆Lvで自動習得（覚える喜びの王道方式）。
- **アクティブスキル**：JP習得式（スキルツリー）。
- **パッシブ**：装備品やスキルツリーで付与（例「毒無効」「クリティカル+5%」）。

| --- | --- | --- |

| 氷 | アイス → ブリザド → アブソリュート | 氷 |

## 4-5. 装備システム

- **装備スロット**：武器 / 盾 / 頭 / 鎧 / 装飾×2。
- **武器種**はキャラ固有（剣・大剣・杖・短剣・魔導銃・刀）。武器ごとに**特性**（例：大剣＝会心時ダメ大／短剣＝2回攻撃確率）。
- **装備の3要素**：①基礎ステ ②属性（属性攻撃/耐性付与）③特殊効果（オートヒール・状態異常耐性・スキル付与）。
- **強化・改造**（リリ加入＝第3章で解放）：
  - **強化値 +0〜+10**：素材＋Goldで攻撃/防御を段階上昇。
  - **属性付与**：素材（炎の結晶など）で武器に属性を1つ付与。
  - **銘（めい）**：レア素材で特殊効果スロットを1つ開放（例「吸血」「会心+10%」）。
- **セット効果**：特定の防具一式を揃えると追加ボーナス（探索のご褒美）。詳細は `08_items.md`。
- **入手バランス**：店売り＝安定／宝箱＝先取り／ドロップ＝レア／改造＝最終調整、の4経路で「収集の楽しさ」を担保。

## 4-6. お金（Gold）と経済

- 通貨：**ギル（G）**。敵ドロップ・宝箱・クエスト報酬・売却で入手。
- 物価カーブ：章が進むごとに装備価格が約1.6倍ずつ上昇。「次の町の装備を全員分は買えない」程度に絞り、**取捨選択の悩み**を作る。
- **売却＝買値の50%**。素材は専門店で高く売れる経路を用意（探索報酬の現金化）。

## 4-7. セーブ・難易度・補助システム

- **セーブ**：いつでもセーブ（フィールド）＋ ダンジョン内セーブポイント（光る星の像）。全年齢配慮で**こまめに保存可能**。
- **難易度**：「やさしい／ふつう／むずかしい」をいつでも変更可。やさしいは被ダメ-30%・取得EXP+20%、むずかしいは敵AI強化＆ボスギミック追加。**ストーリーを楽しみたい層を切り捨てない**。
- **オートバトル & 戦闘倍速**：周回・レベリングの快適性。ボス戦はオート制限（手動推奨警告）。
- **クエストログ／ワールドマップのファストトラベル**（訪問済みの町へ）で探索のストレスを軽減。
- **モンスター図鑑・アイテム図鑑**：収集要素＆裏ボス解放条件の一部（§09）。
