# 7. モンスター設計

## 7-0. 方針

- **通常モンスター50種 ＋ ボス10体 ＋ 裏ボス1体**。
- 設定上、モンスターは**星霜の歪みが生んだ存在**（§01-6）。倒すと「光になって還る」＝浄化。残酷描写なし。
- **ファミリー（系統）**で属性・行動傾向をまとめ、覚えやすく＆使い回しの色替え量産も可能に。
- 表記：`HP/ATK/DEF/MAG/MDF/AGI`。弱点=×1.5、半減/吸収は備考。`EXP`/`Gold`は標準ドロップ。

### 系統(ファミリー)一覧
| 系統 | 傾向 | 代表弱点 |
| --- | --- | --- |
| 獣（Beast） | 物理速攻 | 風/氷 |
| 植物（Plant） | 状態異常・搦め手 | 炎 |
| 虫（Insect） | 数で攻め・毒 | 炎/風 |
| 不死（Undead） | 闇/呪い | 光 |
| 機械（Machine） | 高防御・遠隔 | 雷/土 |
| 水棲（Aqua） | 水/氷 | 雷 |
| 飛行（Flying） | 高回避 | 風/雷 |
| 竜（Dragon） | 高耐久・属性ブレス | 系統で個別 |
| 精霊（Elemental） | 単一属性特化 | 対の属性 |
| 魔（Demon/魔王軍） | 闇・複合 | 光 |

## 7-4. AI・行動テーブル方針（実装メモ）

- 各敵は **行動テーブル（重み付き）** で管理。`通常時 / HP50%以下 / 状態異常付与中` の3パターンを持たせ、単調さを回避。
- ボスは **HP閾値トリガー**（フェーズ移行）と**チャージ予兆（次ターン警告ログ）** を必須実装。
- 状態異常成功率・属性倍率は §05 の式に従い、敵個別の `resist` 値で調整（マスターデータ `balance_enemy.xlsx`）。
