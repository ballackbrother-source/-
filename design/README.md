## 0. ハイコンセプト

> **「滅びを定められた世界で、"星の記憶"を継いだ少年が、かつて世界を救った英雄＝魔王の真実にたどり着く物語。」**

- **ジャンル**：ターン制コマンドRPG（ドラクエ／初期FFの王道フォーマット）
- **テーマ**：継承・喪失・赦し。「英雄はなぜ魔王になったのか」を巡るミステリ構造
- **三本柱**：①感動するストーリー ②探索の発見 ③育成と装備収集の達成感
- **プレイ時間**：メイン 12〜16時間／やり込み込みで 18〜22時間
- **想定ボリューム**：町10／ダンジョン14／通常モンスター50種／ボス10体＋裏ボス1体

## 2. 用語・表記ルール（チーム共有）

- ステータス略称：**HP / MP / STR(ちから) / VIT(みのまもり) / AGI(すばやさ) / DEX(きようさ) / INT(かしこさ) / SPI(せいしん) / LUK(うん)**
- 属性7種：**炎・氷・雷・風・土・光・闇**（無属性は「physical」と表記）
- レアリティ：★1（並）〜★5（伝説）。★5は1周で入手機会が限定されるユニーク。
- フラグ命名：`FLG_章番号_連番`（例 `FLG_3_07`）。イベント分岐は全てフラグ管理。
- 仮タイトル・仮名はすべて変更可。**プレースホルダは `【仮】` を付ける。**

## 3. ターゲット体験（ディレクター方針）

1. **「最初の30分で泣ける入口、最後の30分で泣ける出口」** を必達ライン。OPと真EDで同じ旋律（メインテーマ）を別アレンジで鳴らし、伏線回収と音楽を同期させる。
2. **戦闘は「考えれば必ず勝てる」**。レベリング強行突破も、属性・状態異常の攻略もどちらも正解。理不尽な運ゲーにしない。
3. **探索は「ご褒美の密度」**。1ダンジョンに必ず「分岐の宝箱」「隠し通路」「ミニ物語」を1つずつ。
4. **全年齢**：流血・過度な残酷表現なし。死は「光になって還る」表現で統一。恐怖演出は雰囲気で見せ、グロに頼らない。
